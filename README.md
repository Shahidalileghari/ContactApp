# Contact App 📱

A Flutter-based mobile application for managing contacts efficiently, allowing users to organize and access contact information easily.

## Features
- Add, view, edit, and delete contacts.
- Store names, phone numbers, and other contact details.
- Simple and user-friendly interface.
- Efficient contact management.

## Technologies
- Flutter
- Dart
